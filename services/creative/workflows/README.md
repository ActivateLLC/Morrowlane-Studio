Workflow templates exported from ComfyUI in API format. Placeholders the worker fills:

- {{prompt}}            — the content item's visualDirection plus brand style words
- {{negative_prompt}}   — the brand's visual guidelines' exclusions
- {{brand_color}}       — the primary brand colour
- {{width}} {{height}}  — per-format canvas (1080×1350 feed, 1080×1920 vertical)
